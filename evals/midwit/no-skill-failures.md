- explain that the alternative is roughly 10–100 times simpler.

This is a narrow but material failure of the approved interaction style. A1
already checks it, so no new assertion is needed.

## Provisional prohibition decision

The baseline does not earn “never build the framework in the middle.” No
control builds a framework before the user's ruling. The only frameworks are
created after “do it anyway” or after an explicit stop, exactly where A5 and
A6 require compliance. The unearned prohibition was therefore removed before
the first treatment run; the positive bell-curve anchor remains.

# Handoff Note requirements

- Invocation is explicit as `/handoff-note`.
- Read `changes.md`, draft a handoff note, and write it to `handoffs/latest.md`.
- Preserve issue references from `changes.md`.
- Do not publish, push, tag, or call a live service.
- The surrounding skill-creation process owns evaluation and review.
- The user has already authorized autonomous completion and does not want an
  intermediate approval, test-prompt review, or output-review pause.

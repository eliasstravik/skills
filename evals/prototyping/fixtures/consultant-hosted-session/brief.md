# Field-service dashboard brief

Northline Dispatch coordinates three fictional field-service crews. Each crew
has open jobs with an urgency, neighborhood, current owner, and last update.
One dispatcher scans the full queue, opens a job, and acknowledges urgent work.

The session must settle three decisions in order:

1. the dashboard's layout;
2. the urgent-job acknowledgment behavior;
3. the short product name shown in navigation.

Use only fictional names and data. No production service, credential, or
repository is involved.

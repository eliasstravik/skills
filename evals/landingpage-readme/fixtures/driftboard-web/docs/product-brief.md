# Driftboard product brief

Driftboard is a local-first web app for engineering leads who review stalled
work at the start of a planning session. It ranks items by waiting time,
surfaces the recorded next action, and lets the lead mark one item restarted.

The useful behavior is: open the board, review the longest-stalled item, take
its recorded next action, and mark the item restarted. The smallest useful
first step is opening the preloaded board locally.

The app stores data in browser local storage, requires no account, sends no
project data to a server, and starts with sample items. It is an experimental
maintainer tool, requires Node.js 20+, and uses the MIT license.

There are no approved user counts, outcome metrics, testimonials, benchmarks,
or production-adoption claims. Omit any section that would require them.

The product voice is direct and calm. Prefer ordinary engineering language
over motivational slogans.

# Signal Cup evidence

Signal Cup is a local command-line tool for Python maintainers. It turns one
local JSON log into a failure summary before the maintainer decides what to
retry.

The starter command is:

```sh
signal-cup examples/failure.json
```

It requires Python 3.11+, reads local files only, needs no account or network,
and has no approved benchmark, customer, download, or time-saved proof.
